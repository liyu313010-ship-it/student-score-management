# 学生成绩管理系统

基于 Python + Tkinter + Pandas 的桌面端学生成绩管理与数据分析系统。

## 功能

- 学生信息录入与管理
- 成绩录入与查询
- 基于 Pandas 的成绩统计分析（平均分、最高分、最低分、排名等）
- 图形化界面（Tkinter + ttk）

## 技术栈

- Python 3
- Tkinter / ttk（GUI）
- Pandas（数据处理与分析）

## 文件说明

| 文件 | 说明 |
|------|------|
| `student_mian.py` | 程序入口 |
| `student_gui.py` | GUI 界面逻辑 |
| `student_data.py` | 学生数据管理 |
| `student_analysis.py` | 成绩统计分析 |

## 运行

```bash
pip install pandas
python student_mian.py
```
